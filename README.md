# Wawan Saputra — CV & Research Portfolio

Website portofolio statis berbahasa Indonesia dengan profil, proyek, publikasi, pengalaman, pendidikan, dan pengajaran.

## Menjalankan
Buka `index.html` di browser. Tidak memerlukan instalasi atau proses build.

## Fitur
- Layout responsif
- Filter dan detail proyek
- Tautan publikasi dan kontak
- Cetak atau simpan CV melalui dialog cetak browser

## GitHub Pages
Pilih Settings > Pages > Deploy from a branch, lalu pilih branch main dan folder / (root).

Konten profil diperbarui berdasarkan CV per 31 Oktober 2026.
